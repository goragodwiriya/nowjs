Font Weight & Line Height

--font-weight-normal (400) น้ำหนักปกติ

--font-weight-semibold (600) กึ่งหนา

--font-weight-bold (700) ตัวหนา

มีตัวแปร --font-weight-light (300) และ --font-weight-medium (500) ด้วย แต่ฟอนต์ Sarabun ที่โหลดมามีเฉพาะ 400 / 600 / 700 จึงแสดงเป็นน้ำหนักที่ใกล้ที่สุด

--line-height-tight (1.25)
ระยะบรรทัดชิด เหมาะกับหัวข้อหลายบรรทัด ข้อความภาษาไทยที่มีสระบนล่าง

--line-height-base (1.5)
ระยะบรรทัดปกติของ body ใช้กับเนื้อหาทั่วไปของหน้าเว็บ

--line-height-loose (2)
ระยะบรรทัดห่าง เหมาะกับข้อความที่ต้องการให้อ่านง่าย

ตัวแปรทั้งหมด --line-height-none (1), tight (1.25), snug (1.375), base (1.5), relaxed (1.625), loose (2)

Font Families

--font-family-base: Sarabun ภาษาไทย ABC 0123

font-family: 'Kanit' ภาษาไทย ABC 0123

--font-family-mono: monospace ABC 0123

Sarabun และ Kanit เก็บไว้ในโปรเจ็ค (Now/css/fonts.css) ใช้งานได้แบบออฟไลน์ · เปลี่ยนฟอนต์ทั้งเว็บโดยกำหนด --font-family-base หรือเฉพาะหัวข้อด้วย --font-family-heading


          :root {
            --font-family-heading: 'Kanit', var(--font-family-base);
          }

Paragraphs & Alignment

นี่คือย่อหน้าที่เกิดจาก tag <p>....</p> คุณสามารถใส่เนื้อหาต่างๆได้ภายใต้ tag นี้

จัดตัวอักษรชิดซ้ายด้วย <p class=left>...</p>

จัดตัวอักษรกึ่งกลางด้วย <p class=center>...</p>

จัดตัวอักษรชิดขวาด้วย <p class=right>...</p>

จัดตัวอักษรเต็มบรรทัดด้วย <p class=justify>...</p> ข้อความจะถูกกระจายให้ชิดทั้งซ้ายและขวา เมื่อข้อความยาวเกินหนึ่งบรรทัดจะเห็นผลชัดเจน ข้อความจะถูกกระจายให้ชิดทั้งซ้ายและขวา เมื่อข้อความยาวเกินหนึ่งบรรทัดจะเห็นผลชัดเจน

ใช้ text-left / text-center / text-right / text-justify ได้ผลเหมือนกัน · class left / right / center บน element ที่เป็น .flex จะหมายถึงการจัดวาง flex แทน


          <p class="left">...</p>      <!-- หรือ text-left -->
          <p class="center">...</p>    <!-- หรือ text-center -->
          <p class="right">...</p>     <!-- หรือ text-right -->
          <p class="justify">...</p>   <!-- หรือ text-justify -->

Inline Text

Tag <em> ใช้เน้นข้อความสำคัญ แสดงเป็นตัวสีแดง (ไม่เอียง)

Tag <strong> และ <b> แสดงเป็นตัวหนา

Tag <i> และ <dfn> แสดงเป็นตัวเอียง

Tag <ins> และ <u> แสดงเป็นขีดเส้นใต้

Tag <del> และ <s> แสดงเป็นขีดฆ่า

Tag <mark> ไฮไลต์ข้อความด้วยสีพื้นหลังเหลืองอ่อน

Tag <abbr title="..."> ตัวย่อ (ไม่มีเส้นใต้ ชี้เพื่อดู title)

Tag <sub> และ <sup> ตัวห้อยและตัวยก เช่น H2O, m2

Tag <small> และ <big> ปรับขนาดตัวอักษร หรือใช้ class small และ class big กับ element อื่น

ข้อความหมายเหตุ <p class=comment>...</p> สีเขียว ขนาดเล็กกว่าปกติเล็กน้อย


          <em>สีแดง</em> <strong>หนา</strong> <i>เอียง</i> <u>เส้นใต้</u> <del>ขีดฆ่า</del>
          <mark>ไฮไลต์</mark> H<sub>2</sub>O m<sup>2</sup>
          <span class="small">เล็ก</span> <span class="big">ใหญ่</span>
          <p class="comment">หมายเหตุ</p>

Code, Keyboard & Blockquote

<code> ใช้สำหรับระบุส่วนที่เป็นโค้ด Now.init({...})

<kbd> ปุ่มบนแป้นพิมพ์ กด Ctrl + S เพื่อบันทึก

<samp> ผลลัพธ์จากโปรแกรม Application initialized

<pre> ข้อความที่จัดรูปแบบไว้แล้ว
    รักษาช่องว่างและการขึ้นบรรทัด
    และตัดบรรทัดเมื่อยาวเกิน (pre-wrap)
ใช้สำหรับการอ้างอิงไปยังคำพูด <blockquote>...</blockquote> มีเส้นสีหลักด้านซ้ายและเครื่องหมายคำพูด

          <code>Now.init()</code>
          <kbd>Ctrl</kbd> + <kbd>S</kbd>
          <samp>output</samp>
          <pre>preformatted text</pre>
          <blockquote>quote</blockquote>

Truncation & White Space

.one_line ตัดข้อความให้เหลือบรรทัดเดียวพร้อม ... เมื่อข้อความยาวเกินความกว้างของกล่อง

.two_line ตัดข้อความให้เหลือสองบรรทัดพร้อม ... เหมาะกับคำอธิบายสั้นในการ์ด ข้อความส่วนที่เกินจะถูกซ่อนไว้ ข้อความส่วนที่เกินจะถูกซ่อนไว้

.three_line ตัดข้อความให้เหลือสามบรรทัดพร้อม ... เหมาะกับบทนำของบทความในหน้ารวม ข้อความส่วนที่เกินจะถูกซ่อนไว้ ข้อความส่วนที่เกินจะถูกซ่อนไว้ ข้อความส่วนที่เกินจะถูกซ่อนไว้

.nowrap ไม่ตัดบรรทัด ข้อความจะยาวต่อไปทางขวาจนกว่าจะจบประโยค

.pre-line รักษาการขึ้นบรรทัดของข้อความ เช่น เหตุผล หรือหมายเหตุ ที่ผู้ใช้พิมพ์ไว้หลายบรรทัด

มี .four_line ด้วย · .wrap คืนค่า white-space: normal (บน .flex คือ flex-wrap)


          <p class="two_line">...</p>   <!-- one_line / two_line / three_line / four_line -->
          <td class="nowrap">...</td>
          <p class="pre-line" data-text="reason"></p>
