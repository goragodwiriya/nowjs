File Upload

Complete file upload solution with preview, drag & drop, sorting, and validation

Features Overview

Now.js provides a powerful file upload component with the following capabilities:

📤 Single & Multiple Upload

Support for both single file and multiple file uploads

multiple

👁️ Live Preview

Real-time preview of uploaded images and files

data-preview="true"

🎯 Drag & Drop

Intuitive drag and drop interface for file uploads

data-drag-drop="true"

🔄 Sortable Files

Reorder uploaded files by dragging

data-sortable="true"

🗑️ Remove Files

Delete uploaded files before submission

data-allow-remove-existing="true"

✅ File Validation

Validate file types using accept attribute

accept="image/*, application/pdf"

🔗 File References

Load existing files from URLs

data-file-reference="url"

✂️ Image Crop

Pan, zoom and rotate each picked image in a fixed frame before it joins the field

data-crop="true"

📏 Size Limit

Reject files larger than a limit (bytes, default 10 MB)

data-max-file-size="512000"

🗄️ Server Actions

Delete and reorder files already stored on the server

data-action-url="files-action.php"

🧩 Custom Preview Area

Render previews anywhere on the page

data-preview-container="#box"

📡 Events

Listen for selection changes and finished crops

file:change · file:crop

📊 Form Integration

Seamless integration with Now.js Form component

data-form="settings"

API Reference

File upload input attributes for customization:

Attribute Type Default Description
data-preview boolean false Enable live preview of uploaded files
data-drag-drop boolean false Enable drag and drop functionality
data-sortable boolean false Drag handle on existing files; the new order is posted to data-action-url
data-allow-remove-existing boolean false Show a delete button on existing files (also needs data-action-url)
data-file-reference string - Field name for file URL reference (e.g., "url")
data-attr string - Bind to data source (e.g., "value:files")
data-files JSON / string - Existing files: inline JSON [{"id":1,"url":"..."}] or the name of a field in the loaded data
data-max-file-size number 10485760 Largest file accepted, in bytes
data-action-url string - Endpoint for existing files: {action:"delete", <reference>} and {action:"sort", order:[...]}. Without it existing files cannot be deleted or reordered
data-action-params JSON / string - Extra keys sent with every action: JSON {"id":1} or comma-separated URL query keys id,module
data-preview-container selector - Put previews in this element instead of under the field
data-crop boolean false Open every picked image in ImageCropper; the cropped file is what the form sends
data-crop-aspect string 1 Frame width/height: 1, 3/4, 16:9
data-crop-width number 0 Width of the output image in px (0 = the cropped area's own size, max 2048)
data-crop-shape string rect rect or circle (circle masks the frame only; the file stays rectangular)
data-crop-format string auto auto (keep JPEG/PNG/WebP) · jpeg · png · webp
data-crop-quality number 0.9 JPEG/WebP quality 0–1
data-crop-min-width number 0 Warn when the selected area has fewer source pixels across than this
accept string * Allowed file types (e.g., "image/*,application/pdf")
multiple boolean false Allow multiple file selection

Code Examples

Example 1: Single File Upload with Preview

Upload a single image file with live preview:


            <input type="file"
            name="avatar"
            data-preview="true"
            data-allow-remove-existing="true"
            data-file-reference="url"
            accept="image/*">

Example 2: Multiple Files with Drag & Drop

Upload multiple files with drag and drop support:


            <input type="file"
            name="files"
            multiple
            data-preview="true"
            data-drag-drop="true"
            data-allow-remove-existing="true"
            accept="image/*,application/pdf">

Example 3: Sortable File Upload

Upload multiple files with sorting capability:


            <input type="file"
            name="files"
            multiple
            data-preview="true"
            data-drag-drop="true"
            data-sortable="true"
            data-allow-remove-existing="true"
            data-file-reference="url">

Example 4: Loading Existing Files

Load existing files from API using data binding:


            <!-- HTML -->
            <form data-form="settings"
            data-load-api="settings.php">
            <input type="file"
            name="files"
            multiple
            data-preview="true"
            data-attr="value:files"
            data-file-reference="url">
            </form>
          

            // API Response Format (settings.php)
            {
            "data": {
            "files": [
            {
            "url": "files/sample.jpg",
            "name": "sample.jpg"
            },
            {
            "url": "files/document.pdf",
            "name": "document.pdf"
            }
            ]
            }
            }

Example 5: Form Submission

Complete form with AJAX submission:


            <form method="POST"
            action="save-settings.php"
            data-form="settings"
            data-validate="true"
            data-ajax-submit="true"
            data-load-api="settings.php">

            <input type="text" name="name" required>

            <input type="file"
            name="avatar"
            data-preview="true"
            data-attr="value:avatar"
            data-file-reference="url"
            accept="image/*">

            <button type="submit">Submit</button>
            </form>

Image Crop

With data-crop="true" every image you pick opens in the cropper first: drag to pan, wheel / pinch / slider to zoom, and the rotate button turns it a quarter turn. The cropped file is what the field holds and the form sends; the uncropped original is cleared from the input. Cancel keeps the previous selection. SVG and non-image files skip the cropper.

Crop before upload
data-crop-aspect="1" data-crop-shape="circle" data-crop-width="400" data-crop-format="webp"
Each picked image is cropped in turn. The button on a preview crops it again from the original at the previous crop, so the image is never resampled twice.

file:crop log

Crop an image above: the original and the cropped file appear here.


          <input type="file" name="avatar" accept="image/*"
            data-preview="true"
            data-crop="true"
            data-crop-aspect="1"
            data-crop-shape="circle"
            data-crop-width="400"
            data-crop-format="webp">

          <input type="file" name="files" multiple accept="image/*"
            data-preview="true" data-drag-drop="true"
            data-crop="true"
            data-crop-aspect="16/9"
            data-crop-width="1280"
            data-crop-min-width="800"
            data-crop-quality="0.8">

The crop options are read each time a file is picked, so a form can bind them from its data, e.g. data-attr="data-crop-aspect:aspect". The cropper is a feature bundle (now.imagecrop.min.js + .css) loaded automatically when the page has [data-crop="true"].


          // Every finished crop (data-crop fields)
          EventManager.on('file:crop', ({data}) => {
            // data.elementId, data.file (cropped File), data.source (original File)
            console.log(data.source.size, '→', data.file.size);
          });

ImageCropper.open()

The cropper can be used without a file field. ImageCropper.open(fileOrUrl, options) resolves to a File, or null when the user cancels. A URL must be same-origin or served with CORS.


          await Now.require('ImageCropper');   // load the bundle when no data-crop field is on the page

          const file = await ImageCropper.open('files/sample.jpg', {
            aspect: '4/3',     // 1, 0.75, '3/4', '16:9'
            width: 800,        // output width (0 = natural size, max maxWidth 2048)
            shape: 'rect',     // 'rect' | 'circle'
            format: 'auto',    // 'auto' | 'jpeg' | 'png' | 'webp'
            quality: 0.9,
            minWidth: 0,       // warn below this many source pixels
            maxZoom: 4,
            title: 'Crop image'
          });
          if (file) {
            img.src = URL.createObjectURL(file);
          }

Size Limit, Server Actions & Custom Preview

More options
data-max-file-size="512000" · files over the limit are rejected and the field shows the error
Delete posts {action:"delete", id:101, album:7}; dragging the handle posts {action:"sort", order:[{id, position}], album:7}. The demo endpoint does not change anything on disk.
data-preview-container="#custom-preview-box"

file:change log

Pick or remove files above.


          <input type="file" name="files" multiple data-preview="true"
            data-max-file-size="512000">

          <input type="file" name="gallery" multiple data-preview="true"
            data-sortable="true"
            data-allow-remove-existing="true"
            data-file-reference="id"
            data-action-url="files-action.php"
            data-action-params='{"album": 7}'
            data-files='[{"id": 101, "url": "files/sample.jpg", "name": "sample.jpg"}]'>

          <input type="file" name="photos" multiple data-preview="true"
            data-preview-container="#custom-preview-box">
          <div id="custom-preview-box" class="file-preview"></div>
        

          // Selection changed (pick, drop, remove, re-crop)
          EventManager.on('file:change', ({data}) => {
            // data.elementId, data.files (Map of name → File)
            console.log(data.elementId, [...data.files.keys()]);
          });
